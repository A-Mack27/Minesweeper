Here's how to add the database to your MSSQLLocalDB

Right click the databases file and press 'Publish Data-tier Application'

![image](https://github.com/user-attachments/assets/639a3b0c-2606-4708-b67c-1c3c157ceb18)


Locate the UserProfileDatabase.dacpac file on disk
Set the database name to UserProfile (exact name with capital letters)


![image](https://github.com/user-attachments/assets/af5bad25-ef43-49a1-85d7-d5ef088047f8)


Press publish
